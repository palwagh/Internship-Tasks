# TASK 1 – Text Summarization Tool (CODTECH Internship)

## Internship
CODTECH

## Task Title
Create a tool that summarizes lengthy articles using Natural Language Processing (NLP) techniques.

## Description
This task focuses on building a Python-based text summarization tool.
The tool takes a long input text and generates a concise summary using NLP techniques.

## Objective
- Understand basic NLP concepts
- Implement automatic text summarization
- Reduce long articles into meaningful summaries

## Deliverable
A Python script that:
- Accepts input text
- Processes the text using NLP
- Outputs a concise summary

## Technologies Used
- Python
- Natural Language Processing (NLP)
- NLTK Library

## Outcome
Successfully built a working text summarization tool in Python.
